- Was ist der Unterschied zwischen Capacitor und Cordova?
    -> Capacitor ist der moderne Nachfolger von Cordova, entwickelt vom Ionic Framework-Team.

- Was macht ein ORM wie Sequelize, und wofür braucht man zusätzlich die sequelize-cli?
    -> ORM (Object-Relational Mapping) wie Sequelize sorgt dafür, dass du SQL-Datenbanken (wie PostgreSQL, MySQL oder SQLite) verwenden kannst, ohne selbst SQL-Code schreiben zu müssen.
    -> Die sequelize-cli (Command Line Interface) ist ein Werkzeug für das Terminal und übernimmt Aufgaben wie Projekt-Initialisierung, führt Änderungen auf der Datenbank, generiert Migrations-Dateien und mit einem Befehl kann sie mit "Seeders" deine Datenbank schnell mit initialen Daten oder Testdaten befüllen.

- Was unterscheidet npm install von npx beim Ausführen eines Pakets?
    -> npm install installiert Pakete dauerhaft als Abhängigkeit in Ihr Projekt oder System, während npx Pakete direkt ausführt, ohne dass eine vorherige dauerhafte Installation erforderlich ist.
